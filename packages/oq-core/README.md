# oq-core

The source model, diagnostics, lexer, parser, AST, and semantic analysis. This is the only package allowed to define language syntax and meaning.

**Status: Phase 0 scaffold.** This distribution exists so the workspace layout,
packaging, namespace sharing, and installation are verifiable. Phase 0 provides the source model and diagnostics. The lexer and parser arrive in Phase 1.

No support is claimed for anything not listed in the root
[`PROJECT_STATUS.md`](../../PROJECT_STATUS.md). Current limitations are in
[`KNOWN_LIMITATIONS.md`](../../KNOWN_LIMITATIONS.md).
