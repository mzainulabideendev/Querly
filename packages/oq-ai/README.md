# oq-ai

An optional natural-language helper. It is never required to parse, compile, or execute Querly programs.

**Status: Phase 0 scaffold.** This distribution exists so the workspace layout,
packaging, namespace sharing, and installation are verifiable. The assistant arrives in Phase 9, after the deterministic toolchain is complete.

No support is claimed for anything not listed in the root
[`PROJECT_STATUS.md`](../../PROJECT_STATUS.md). Current limitations are in
[`KNOWN_LIMITATIONS.md`](../../KNOWN_LIMITATIONS.md).
