# oq-converter

Schema and query conversion with per-construct compatibility reporting. Never claims a lossless conversion that is not proven.

**Status: Phase 0 scaffold.** This distribution exists so the workspace layout,
packaging, namespace sharing, and installation are verifiable. The converter arrives in Phase 6.

No support is claimed for anything not listed in the root
[`PROJECT_STATUS.md`](../../PROJECT_STATUS.md). Current limitations are in
[`KNOWN_LIMITATIONS.md`](../../KNOWN_LIMITATIONS.md).
