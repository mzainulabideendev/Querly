# oq-compiler

Normalization, capability analysis, planning, and target artifact orchestration. Never depends on a concrete database driver.

**Status: Phase 0 scaffold.** This distribution exists so the workspace layout,
packaging, namespace sharing, and installation are verifiable. The compiler pipeline arrives in Phase 3.

[`PROJECT_STATUS.md`](../../PROJECT_STATUS.md). Current limitations are in
[`KNOWN_LIMITATIONS.md`](../../KNOWN_LIMITATIONS.md).
